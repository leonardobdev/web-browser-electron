# web browser electron

Standalone app for web browser in electron



## Download

Windows: [browser.exe](https://github.com/leonardobdev/web-browser-electron/releases/download/v1.0.0/browser.exe)

Linux: [browser.AppImage](https://github.com/leonardobdev/web-browser-electron/releases/download/v1.0.0/browser.AppImage)

VirusTotal result: [browser.exe](https://www.virustotal.com/gui/file/) | [browser.AppImage](https://www.virustotal.com/gui/file/)

## How to build the project

```bash
# Install dependencies
npm install

# build the project
npm run dist
```
